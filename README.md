# fraud-detection-conformal-uncertainty
Real‑time credit card fraud detection with cost‑sensitive XGBoost, split conformal prediction, adaptive conformal inference (ACI), and MMD‑based drift detection. Achieves AP 0.79, Brier 0.0027, and $7,490 expected cost on imbalanced data (0.17% fraud rate). Includes SHAP analysis and change point detection.
